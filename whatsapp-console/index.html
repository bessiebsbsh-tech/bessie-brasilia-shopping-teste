Área administrativa privada para envio pela API oficial do WhatsApp.

Antes de enviar

Esta primeira versão envia apenas modelos (templates) aprovados pela Meta. O acesso precisa estar protegido pelo Cloudflare Access. Não use este painel para contatos sem consentimento.

Inclua código do país e DDD. Ex.: 5561999999999.

Use apenas parâmetros que correspondam ao template aprovado. Não coloque dados sensíveis.

Aguardando configuração do backend seguro.

Segurança: nunca informe tokens da Meta nesta página. Eles devem ser cadastrados como secrets no Worker da Cloudflare. Envio em lote e automações de cadência não estão habilitados nesta versão inicial.
